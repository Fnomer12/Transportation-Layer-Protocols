# Transport Layer Protocols – TCP vs UDP

This project demonstrates practical implementation of TCP and UDP transport layer protocols using Python socket programming.

## Features

- TCP Client-Server Communication
- UDP Client-Server Communication
- Latency Measurement
- Packet Loss Simulation
- Multi-threading
- Real-time Networking

## Technologies Used

- Python 3
- Socket Programming
- VS Code
- macOS

### TCP Server
